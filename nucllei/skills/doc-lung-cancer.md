# 診療ガイドライン・CTCAE の引き方

本スキルが扱うのは下表の**肺癌・胸膜中皮腫・胸腺腫瘍 (2025) と CTCAE だけ**。同じ `/ext/doc/診療ガイドライン/` の下にある
次の 2 ディレクトリは引き方が別物なので、それぞれの skill をロードする:

- `/ext/doc/診療ガイドライン/神経疾患/` (日本神経学会 掲載 27 ディレクトリ。版が 2009〜2025 とばらばら・追補版あり・CQ 番号の体系がガイドラインごとに違う) → `doc-neurology` skill
- `/ext/doc/診療ガイドライン/皮膚疾患/` (日本皮膚科学会 掲載 61 ディレクトリ。**皮膚悪性腫瘍 7 本 (メラノーマ等) もこちら**。推奨度の体系が資料ごとに違い、使用ガイダンス・補遺・推奨決定資料が子セクションに入る) → `doc-dermatology` skill

この 3 癌種以外のがん (胃癌・大腸癌・乳癌など) の診療ガイドラインは doc に収録していない。がん登録の項目・コードは
`/ext/doc/がん登録/` (`doc-cancer-registry` skill)、PS・RECIST などの評価スケールは `/ext/doc/臨床スケール/` (`doc-clinical-scales` skill)。

**レジメン (薬剤・用量・投与スケジュール) は CQ のノードに無い。** 原本が項末にまとめているものを、章ディレクトリ (`…/<章>/`) の本文の
「項末のレジメン」区画に収めてある (`/ext/doc/診療ガイドライン/肺癌2025_非小細胞癌/`・`/ext/doc/診療ガイドライン/肺癌2025_小細胞癌/`・
`/ext/doc/診療ガイドライン/肺癌2025_転移/`・`/ext/doc/診療ガイドライン/胸腺腫瘍2025_治療/` の 4 章)。用量を聞かれたら CQ の推奨文で止まらず、その章ディレクトリ (`…/<章>/`) を `read_doc` する
(CQ 側に `注: 項末のレジメンは … にある` の道しるべがあるものはそれに従う)。推奨行末尾の `投票実施年度` は
同じ CQ 内で推奨ごとに年度が違うことがある (再投票) ので、合意率と一緒に引用する。

## 原典 (Web 版) の示し方

この 3 癌種の原典は日本肺癌学会の Web 版 (HTML) で、原本 PDF は無い。各 CQ ノードの末尾に
`原本 Web: [<ガイドライン名> <章> CQ<N>](https://www.haigan.gr.jp/…#cq<N>)` の行がある。章ディレクトリの本文の
項末のレジメンでは各区画の `出典: <https://…>` が同じもの (用量を答えた後に原典を聞かれたらこちら)。
本文の参考文献 (PubMed 等) は推奨の根拠論文であって、原典の代わりにしない。

- `原本 Web:` の外部 URL を貼るのは**原典・URL を求められたときだけ**。出典は通常どおり主張の直後に付ける (`原本 Web:` は出典とは別の普通のリンク)
- 貼るときは CQ ノードの `原本 Web:` 行をリンクの形のまま写し (項末のレジメンの `出典: <…>` は `<…>` の中身を 1 文字も変えずに URL にして `[ラベル](URL)` で書く)、**院内の閉域ネットワークからは開けない
  (院外の端末やスマートフォンでは開ける)** と添え、「スマートフォンで開くなら QR コードを作れる」と 1 行勧める。
  外部なので `fetch_url` / `send_to_workspace` に渡しても届かない (中身は `read_doc` の本文が原典の転記)
- QR は求められたときだけ作る (1 URL につき 1 枚)。`run_python` で `segno` を使い、作業場所に PNG で作ってから
  `/workspace/exports/` へ写す (その場で表示されるので本文に貼り直さない):

```python
import os, shutil, segno
out = "/workspace/<YYYYMMDD>-<作業名>/qr_<CQ番号>.png"
os.makedirs(os.path.dirname(out), exist_ok=True)
segno.make_qr("<原本 Web の URL をそのまま>").save(out, scale=8)
shutil.copy(out, "/workspace/exports/")
```

CTCAE には項目ごとの原典 URL が無い。出典を聞かれたら `/ext/doc/診療ガイドライン/CTCAEv5_JCOG_2025/` の「出典・利用条件」節を
`read_doc` で引いて、その記載のまま示す (原典 URL は作らない。出典は通常どおりそのノード)。

- 該当カテゴリが分かる → `list_doc` で辿って CQ 一覧から選ぶ

## 有害事象規準 (CTCAE) — 収録上は `/ext/doc/診療ガイドライン/` 配下

| path | 範囲 |
|---|---|
| `/ext/doc/診療ガイドライン/CTCAEv5_JCOG_2025/` | CTCAE v5.0 - JCOG (MedDRA/J v28.1, 2025-09-01 改訂) / 全 26 SOC / 837 有害事象用語 |

CTCAE は概念上は「有害事象規準」だが、収録上は `/ext/doc/診療ガイドライン/CTCAEv5_JCOG_2025/` に置いてある (root `/ext/doc/` の直下には出ない)。触るときはこの literal path を使う。

**1 SOC = 1 リーフ**として収録 (AE 単位ではリーフ化していない)。SOC ファイル内に当該 SOC 配下の全 AE が Grade 1〜5 + 定義 + 検索上の注意つきで列挙されている。リーフ名は器官別大分類 (SOC) なので **AE 名 (例: 好中球数減少) から所属 SOC は推測できない**。特定 AE の Grade を引くときは navigate せず、まず `grep_doc("好中球", path="/ext/doc/診療ガイドライン/CTCAEv5_JCOG_2025/")` のように**語幹で**直接検索し、ヒットした SOC を `read_doc` する。**検査値系の AE は「〜数減少」「〜増加」の表記**なので (`好中球数減少` `リンパ球数減少` `血小板数減少` `クレアチニン増加`)、`好中球減少` のような日常語で引くと `血液およびリンパ系障害` の発熱性好中球減少症などにしか当たらない。

0 件でも即断せず、短く切る・別表記・カタログから `list_doc` で辿る、の 3 段を試す。CTCAE で効く当て方: 複合語は部分語が当たる (`発熱性好中球減少症` → `好中球`、`間質性肺炎` → `肺炎`)、略語と正式名 (`FN`)、SOC 一覧 (`read_doc("/ext/doc/診療ガイドライン/CTCAEv5_JCOG_2025/")`) から障害部位で当たりを付ける。3 つ試して無ければ「この AE 名では収録を確認できなかった」。
**Grade を記憶から答えない。** 閾値はヒットした SOC の本文から逐語で引く。

例 (代表的な SOC path):
- `/ext/doc/診療ガイドライン/CTCAEv5_JCOG_2025/血液およびリンパ系障害.md`
- `/ext/doc/診療ガイドライン/CTCAEv5_JCOG_2025/心臓障害.md`
- `/ext/doc/診療ガイドライン/CTCAEv5_JCOG_2025/胃腸障害.md`
- `/ext/doc/診療ガイドライン/CTCAEv5_JCOG_2025/臨床検査.md`
- `/ext/doc/診療ガイドライン/CTCAEv5_JCOG_2025/神経系障害.md`
- `/ext/doc/診療ガイドライン/CTCAEv5_JCOG_2025/感染症および寄生虫症.md`
- `/ext/doc/診療ガイドライン/CTCAEv5_JCOG_2025/皮膚および皮下組織障害.md`

全 26 SOC の一覧と Grade 一般定義・ADL・"nearest match" 原則は `/ext/doc/診療ガイドライン/CTCAEv5_JCOG_2025/` (このディレクトリの本文) に集約。
Grade 判定、SOC ごとの用語一覧、用語の定義、関連する別 AE への参照 (検索上の注意) を引きたいときはこちら。
