- **資料を特定できているなら `path` で必ず絞る** — `grep_doc(query="デュピルマブ", path="/ext/doc/診療ガイドライン/皮膚疾患/アトピー性皮膚炎2024/")`。

  絞らずに引くと上位 10 件が関係の薄いノードで埋まる (ステロイド外用・抗ヒスタミン薬・シクロスポリン・
  生物学的製剤・紫外線療法は特に散る)

## 推奨度の体系が資料ごとに違う (跨いで比較しない)

CQ ノードの title 末尾【】には**原本の記号をそのまま**入れてある。体系は少なくとも 4 系統が混在する:

- **旧 Minds 式 推奨度 A / B / C1 / C2 / D + エビデンスレベル I〜VI** — 多数
  (`SJS・TEN` `尋常性痤瘡・酒皶2023` `血管炎・血管障害2016` `頭部血管肉腫` `痒疹2020` `皮膚瘙痒症2020`
  `疥癬第3版` `尋常性疣贅2019` `接触皮膚炎2020` `手湿疹` `掌蹠角化症` `膿疱性乾癬2014` `類天疱瘡` ほか)
- **新 Minds / GRADE 式 推奨の強さ (数字) + エビデンスの強さ A〜D** — **段階数は資料ごとに違う** (1〜2・1〜3・1〜4・1〜5・「推奨なし」)。
  皮膚悪性腫瘍 2025 の 7 本、`アトピー性皮膚炎2024` `蕁麻疹2026` `円形脱毛症2024` `好酸球性筋膜炎`
  `硬化性萎縮性苔癬` `限局性強皮症2026` `尋常性白斑2025` `皮脂欠乏症2021` `血管腫・脈管奇形2022` ほか
- **推奨度 + 同意度/合意度の併記** — `ベーチェット病皮膚粘膜病変` `家族性良性慢性天疱瘡2023` (平均同意度)、
  `穿孔性皮膚症` (同意度)、`限局性強皮症2026` (合意度 中央値[四分位範囲])、皮膚悪性腫瘍 2025 (合意率)
- **語で書くもの・推奨度が付かないもの** — `天疱瘡2026` (強く推奨／弱く推奨／行わないことを提案…)、
  `皮膚血管炎・血管障害2023` (推奨の強さ 強い/弱い + エビデンスの確実性 高〜非常に低)、
  `創傷・褥瘡・熱傷2023` (強い推奨／弱い推奨)、
  `美容医療診療指針` 第 6 章 (**CQ でなく「回答」形式で推奨度が付かない**)、
  `掌蹠膿疱症2022` と `壊疽性膿皮症2022` の一部 CQ (**推奨度 未設定**)、
  `白癬菌抗原キット` `難治性皮膚潰瘍PRP治療` `水疱型先天性魚鱗癬様紅皮症` `結節性硬化症2024`
  `皮膚疾患遺伝子診断第1版` `無汗性外胚葉形成不全症` `色素性乾皮症` `化膿性汗腺炎2020` (CQ 無し)、
  `接触皮膚炎2020` (**CQ 番号は付かないが、治療法の EBM の節には旧 Minds の推奨度が付く**)

守ること: **資料をまたいで「推奨度 B」「1B」を比較しない。** 同じ `A` でも旧 Minds の A
(行うよう強く勧められる) と新 Minds のエビデンスの強さ A (エビデンスが強い) は別物。
**新 Minds 式の数字は強さだけで、向き (行う/行わない) は括弧の中にある** —
`皮膚リンパ腫2025` は `1（実施することを推奨）` `3（実施しないことを提案）`、
`美容医療診療指針` は 2 段階しかなく `1（行わないことを強く推奨する）` という使い方もする。
**数字だけを取り出さず、括弧ごと逐語で示す。** 記号の意味はその資料のディレクトリ (`…/<資料>/`) の本文か
「エビデンスレベルと推奨度」の節で確かめる。
1 つの CQ が**部位別・病型別・薬剤別・性別に複数の推奨度**を持つものがある
(`原発性局所多汗症2023` は頭部顔面/腋窩/手掌/足底、`男性型および女性型脱毛症2017` は男性型/女性型、
`限局性強皮症2026` は治療の組合せごと)。**1 つだけ抜き出して「推奨度は B」と言わない**

## 本文の読み方の注意

- **原本はすべて日皮会誌などの 2 段組で、本文は段ごとに読める。**
  ただし **段抜きの表・図はページ末尾に回る** — 表が属する節の見出しより後ろに出たり、
  ページをまたぐ節では**次の CQ ノードの先頭に載ってしまう**ことがある (再現テキストに
  置き換わっていないページで起こる)。**表を根拠にするときは、その表が本当にその CQ のものかを
  本文の参照 (「表3 に示す」等) で確かめ、隣のノードも見る**
- **図・アルゴリズム図・診断基準表は、ページ画像から起こした再現テキストになっているページがある**。フローチャートは矢印の向きを箇条書きにし、結合セルのある表は値を各行に展開してある。
  **原本に無い列名・辺・説明は足していない**ので、注記 (「原本に見出し行は無い」「原本では結合セル」
  「表中の空欄のセルは原本でも空欄である」) はそのまま読者に伝える。
  再現テキストが多いのは**皮膚悪性腫瘍 2025 の推奨決定資料** (全ページ) と
  **`蕁麻疹2026` の `92_別表2` / `93_別表3`** (構造化抄録と検索式の表)
- **推奨決定資料の EtD フレームワークの「判断」と「判断の要約」は再現テキストで読める。**
  選択肢の頭の **`●` が原本で選択されたもの、`○` (`◯`) が選択されなかったもの**で、
  各表の直前の `（注記：…）` がその対応を名乗る。**原本でどの選択肢も塗られていない項目には
  「いずれも選択されていない」と注記してある** — そこを「選ばれた判断」として読まない
- **図の切り出し画像がある** (507 点)。診療アルゴリズム・治療フローチャート・診断基準や
  重症度分類の記入様式・臨床写真・病理組織像がこの形で入っており、`![図: <説明>](<URL>)` の
  alt にその図が何かが書いてある。図に触れるなら先に `feed_image(url=)` で見て、リンクは戻り値の markdown をラベルごとそのまま使う (URL を組み立てない)。
  **図が無く本文だけ再現されているページのほうが多い**ので、ページやファイル名の規則から
  「図があるはず」と推測しない
- **原本自身の誤記・不整合は直さずに転記してある。** 表の見出しが他の CQ とずれている、
  表の項目が行と 1 対 1 に揃っていない、本文の CQ 番号と表の「関連する CQ」が食い違う、といった箇所には
  その表の直前の `（注記：…）` が「原本の表記のまま転記した」「対応づけの解釈は加えていない」と名乗る。
  **どちらかを正として断定せず、原本が食い違っていることを伝える**
- **表は列順が入れ替わったり数字が 1 桁ずつ分かれたりする** (再現テキストに置き換わっていないページ)。
  用量・スコア・カットオフ値を表から読むときは、崩れている可能性を添えるか原本 PDF で確かめる
- **`> (このページはテキスト層がほぼ無く、図・表として原本 PDF を参照してください)` が入っているページは
  図・表が主体**で本文からは中身が読めない。該当は **9 ページ**で、
  `血管腫・脈管奇形2022` の 7 ページ (章の扉・サマリー) と
  `美容医療診療指針` の表紙・奥付の 2 ページだけ。
  **そこに何が書いてあるかを推測して埋めない。** 自分で確かめたいときは `feed_image(url=…)`
  (その PDF の `#page=N` 付きリンクをそのまま。特定ページを複数見るときだけ `pages` を付ける) で見てから語る
- 本文は原文準拠で**行の結合をしていない** (PDF の折り返しがそのまま)。逐語引用するときは改行が原本どおりであることを理解した上で、意味の切れ目で引く

- **URL は `read_doc` の戻り値にある literal を `#page=` の数字以外 1 文字も変えずにコピーする。**
  上表の資料名やディレクトリ名からファイル名を組み立てない (配信ファイル名は原本 URL 由来の英数字で、
  ディレクトリ名とは別物。配信 URL は `docs/<slug>.pdf` の短い英数字で、percent-encode は入っていない)
- **差し替えてよいのは `#page=` の数字だけで、その行が名乗る `p.A–B` の範囲内に限る。**
  判断できなければ**差し替えず `原本 PDF` の行のリンクをそのまま出す**
- **1 ノードに `原本 PDF` の行が複数あることがある** (本体 + 推奨決定資料、分冊、別表)。
  引用したページを含む区間の行を選ぶ
- `【p.N】` と `#page=N` はどちらも**その PDF の物理ページ**。日皮会誌の通しページ (柱・ノンブル。
  「2055」のような 4 桁) とは別物なので、**印字された数字を `#page=` に入れない**
- **章ディレクトリ (`…/<章>/`) の本文の `原本 PDF` 行は配下全体の範囲**。CQ を引いたならその CQ のノードの行を使う
- `原本 PDF` の行が無いノードで原本 PDF のリンクを**作らない** (出典は通常どおり主張の直後に付ける)。ガイドライン名・章・ページだけを添える
- **引用は原文どおり短く。** 逐語引用は引用と分かる形 (かぎ括弧か引用ブロック) にし、
  自分の要約と混ぜない。見出しや推奨文の言い換えもしない
