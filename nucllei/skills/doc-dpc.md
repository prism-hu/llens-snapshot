# DPC (診断群分類) 電子点数表の引き方

`/ext/doc/診療報酬/DPC点数表R08/` 配下。厚生労働省の **診断群分類 (DPC) 電子点数表** (xlsx 19 シート) を **1 分類 = 1 ノード**に組み直したものと、留意事項通知・参加手続き通知の全文、当院 (北海道大学病院) の医療機関別係数。

| | |
|---|---|
| 版 | **令和8年度診療報酬改定・正式版 2026-08-12 更新分** (正式版 6 本目。2026-09-05 取得) |
| 適用 | **2026-06-01 から**。ただし年度途中から効く行がある (下記) |
| 出典 | 厚生労働省 改定特設ページ「第６ 電子点数表等」「８．ＤＰＣ」(公共データ利用規約 PDL1.0) |

**医科点数表 (出来高) とは別の点数表。** 出来高の点数・算定要件・施設基準・疑義解釈は `doc-shinryo-hoshu` skill (`/ext/doc/診療報酬/医科点数表R08_基本診療料/`・`/ext/doc/診療報酬/医科点数表R08_特掲診療料/` ほか)。DPC の包括払いでも手術・麻酔・リハビリ・1,000 点以上の処置などは出来高で別に算定するので、**「入院の請求」を丸ごと聞かれたら両方の点数表が要る**。

分類ノードの本文は上から **(1) 14 桁コードの組み立て (この分類で各桁に入る値と名前、例 1 本) → (2) 対象傷病 (ICD-10) → (3) 分岐の定義 (手術 / 処置等１ / 処置等２ / 定義副傷病 / 重症度等。使う軸だけ) → (4) 点数表 (この分類の全 14 桁。入院日Ⅰ/Ⅱ/Ⅲ と 1 日あたり点数Ⅰ/Ⅱ/Ⅲ、包括対象外は備考) → (5) 注意**。**path を分類名から組み立てない** (ディレクトリ名に `、` `・` が入る)。

## doc を読むだけで答えられる問い

| 問い | 手順 |
|---|---|
| 傷病名 / ICD → どの分類か | `grep_doc(query="<ICD か傷病名>", path="/ext/doc/診療報酬/DPC点数表R08/")` → 当たった分類ノード (か `対象傷病` 子) を read。**ICD の下位は `$` で束ねてある** (`C71$` = C710〜C719) ので、`C719` で当たらなければ `C71` で引き直す。**当たった行が「対象傷病」の表にあるか確かめる** — 同じ ICD が別の分類の「定義副傷病」の表にも出る (肺炎の ICD は脳腫瘍ノードの副傷病表にある)。副傷病表の一致は分類を決めない |
| 14 桁を組む | 分類ノードの「14 桁コードの組み立て」の表を上から埋める。使わない桁は `x`。**値の意味は分類ごとに違う** (`03` が脳腫瘍では頭蓋内腫瘍摘出術等、別の分類では別の手術) ので必ずその分類の表で読む。組み方の例が各ノードに 1 行ある |
| 入院期間Ⅱの日数と点数 | 点数表の行。入院日Ⅱ = 「その日数**まで**が期間Ⅱ」(Ⅰ+1 日目〜Ⅱ日目)。点数は **1 日あたり・係数を掛ける前** |
| この手術は分岐に入るか | 「手術」の表 (100 行超は子ノード `手術の定義`)。**1 列目「9〜10 桁目」= 対応コード**が 14 桁に入る値。表に無い手術は `97` (その他の手術あり、ダミー `KKK1`) — **`99` (手術なし) ではない** |
| この 14 桁は包括対象外か | 点数表の備考に **包括対象外** (医科点数表で算定) と明記。点数の 6 列が `—` |
| 当院の係数 | `00_北大病院の係数`。基礎 1.1245 + 機能評価係数Ⅱ 0.0823 + 救急補正 0.0057 + 激変緩和 0 = **1.2125 + 機能評価係数Ⅰ** |
| 包括される範囲 / 出来高で取れるもの | `00_算定方法` の項 2 (包括に含まれない費用の一覧: 病理標本作製・HIV 薬・血友病製剤・特定保険医療材料 等) と `00_DPC留意事項通知/第３…` を read。`00_DPCの読み方` の要約で済ませない |
| ICU / HCU / NICU に入った日の DPC 加算 | `00_特定入院料のDPC加算`。**当院は項 4 (特定機能病院) の表**を引く (項 5・6 は別の病院群)。期間 (3 日以内 / 4〜7 日 …) で日額が変わる。特定入院料の出来高点数 (医科点数表 A300 系) は足さない |
| 入院期間Ⅲを超えた日 / 月をまたいで分類が変わった (調整日) | `00_算定方法` の項 15 / 項 16。要約せず条文を引く |
| DPC 対象外の患者・退院時の分類決定・再入院 | 第１ (対象患者) / 第２ (分類の決め方) / 第３の1(7) (7 日以内の再入院) |
| A-DROP、市中肺炎、Child-Pugh、化学療法の定義 | 分類ノードには無い。`00_DPC留意事項通知/第２…` の 3 (10)〜(20) |

## 答えるときの注意 (言わせないこと)

- **コードの最終決定は医事課と主治医。** ここから出すのは「候補の 14 桁とその根拠 (どの表のどの行に当たったか)」まで。「医療資源を最も投入した傷病名」の決定は主治医で、doc からは決められない。複数の 14 桁に当たりうるときは候補を全部並べ、「原則として後ろの行 (ツリー図で下) を優先」は**原則**と添える (ツリー図そのものは未収録)
- **点数は 1 日あたりで、係数を掛ける前。** 「入院費は◯点」「◯円」と言わない。請求点数 = 1 日あたり点数 × 医療機関別係数 × その月の入院日数 + 出来高分、で、**患者負担は負担割合・保険種別で変わる**ので点数までにとどめる
- **機能評価係数Ⅰは当院の届出次第で、doc に合計値は無い。** 係数を出すときは「1.2125 + 機能評価係数Ⅰ」の形にする。概算で数字を出すなら「係数Ⅰを含まない」と必ず添え、確定値のように書かない。**届出の有無は 医事課 (施設基準係)** へ。`/ext/doc/院内マニュアル/施設基準届出状況/` は専任・専従の名簿で届出一覧ではない
- **入院日Ⅲを超えた日は出来高 (医科点数表)。** Ⅲ超の日まで点数Ⅲで積まない。期間の境界は「入院日Ⅱ = 18」なら **18 日目までが期間Ⅱ、19 日目から期間Ⅲ**
- **「対象傷病の表に無い = DPC 対象外」と言わない。** `$` (下位すべて) と `M!!!!` (ICD テーブルに載っていない M コードすべて、071030) の包括的記法があり、別の分類に載っていることもある。`/ext/doc/診療報酬/DPC点数表R08/` 全体を grep してから、それでも無ければ「該当する分類が見つからない → 医事課で確認」。**DPC 対象外の判断は通知 第１の条件 (入院 24 時間以内の死亡・臓器移植・出来高算定手術等・対象外病棟 など) で行う**
- **「手術フラグ (定義フラグ)」と「対応コード」を取り違えない。** 14 桁の 9〜10 桁目に入るのは対応コード (表の 1 列目)。定義フラグ 12〜17 のような手術は対応コードが `97` に束ねられている。処置等１/２・副傷病も同じ
- **点数Ⅱが `-` の行は「期間Ⅱが無い」(入院日Ⅰ = Ⅱ)** であって 0 点ではない (6 行)
- **年度途中から効く行がある。** 表の中で **太字の注記 (変更区分 3 新規、2026-07-15 / 2026-08-13 から)** が付いた行 (処置等２ 3 行 = 040110 ネランドミラスト・080105 免疫グロブリン 2 剤、出来高算定手術等コード 29 行 = 高額薬剤) は **6/1 適用ではない**。その行を根拠にするときは開始日を添える
- **CCP マトリックス (010060 脳梗塞・040080 肺炎等)** は複数の 14 桁が同じ「支払分類」(`010060xxCCPM01`) にまとまって同じ点数。**レセプトに書くのは 14 桁**で、CCPM の番号ではない
- **収録時点を添える。** 「令和8年度改定・正式版 2026-08-12 更新分 (2026-09-05 取得)」。正式版は訂正で積み上がるので、これより新しい正式版が出ていればそちらが正
- **DPC の疑義解釈 (Q&A) は `/ext/doc/診療報酬/疑義解釈R08/DPC/`** (別添「医科診療報酬点数表関係（ＤＰＣ）」、その12 まで・175 問。別添の見出しごとに 1 ノード = 対象病院の基準 / 対象患者 / 分類の適用の考え方 (医療資源病名・手術・処置等・副傷病) / 係数 / 特定入院料 / 再入院 / 退院時処方 / 他医療機関受診 / 明細書 など。問番号は `問３－１－４` 形)。制度の解釈・請求手順を聞かれたらここも read し、「その N 問 M」と収録時点を添える。**医科の区分ノード (`疑義解釈R08/<部>/…`) には DPC の問は無い** — そこだけ見て「疑義解釈は無い」と言わない
- **未収録**: ツリー図 (別添1)・定義テーブル (別添2)・コーディングテキスト、歯科・調剤の点数表。聞かれたら原本を案内する。算定告示の本文 (項 1〜20) と特定入院料の加算表は `00_算定方法` / `00_特定入院料のDPC加算` に**ある**

## 分類をまたいで調べたいとき (xlsx + run_python)

分類をまたぐ横断・数値条件 (「◯◯ (K コード) を分岐に持つ分類を全部」「入院日Ⅱが 30 日以上の 14 桁」「包括対象外の 14 桁の数」) は doc では引けない (1 ノード = 1 分類)。電子点数表の原本 xlsx を sandbox の pandas で直接読む (取り込みは不要)。

```
原本 xlsx: /ext/doc-static/dpc/dpc_20260812.xlsx (openpyxl 同梱)
係数の別表: /ext/doc-static/dpc/keisu_beppyo_R08.xlsx
```

原本そのものをユーザーに渡したいときは、上のパスは同じ文字列が配信 URL なので、その literal をそのままリンク先にして `[ラベル](…)` で本文に書く。

- **シート名の末尾に空白があるものがある** (`６）手術 ` / `12）変換テーブル ` / `13)出来高算定手術等コード `)。`sheet_name="６）手術"` は KeyError になる — `pd.ExcelFile(path).sheet_names` を見て**その文字列をそのまま**使うか、`{n.strip(): n for n in x.sheet_names}` で引く
- ヘッダが 2〜4 行 (シート 11 は空行 2 + ヘッダ 2)。**`header=None, dtype=str` で読み、データ行は列の中身で濾す** (行番号の決め打ちをしない)
- 列は 0 始まりの位置で引く (主なシート):

| シート | 列 |
|---|---|
| `２）分類名称` | 0 MDC / 1 分類コード / 2 名称 / 3 変更区分 / 4 開始日 / 5 終了日 |
| `４）ＩＣＤ` | 0 MDC / 1 分類コード / 2 ICD 名称 / 3 **ICD コード** (`$` 付き) / 4 変更区分 |
| `６）手術 ` | 0 MDC / 1 分類コード / 3 手術フラグ / 5 **対応コード** (9〜10 桁目) / 6,7 手術１の名称・K コード (8〜15 は「＋」で組む 2〜5 番目) / 16 変更区分 |
| `８）手術・処置等２` | 0 MDC / 1 分類コード / 2 **対応コード** (12 桁目) / 3 フラグ / 4,5 名称・コード / 8 変更区分 / 9 開始日 |
| `９）定義副傷病名` | 2 対応コード / 3 フラグ (1 共通 / 2 手術なし / 3 手術あり) / 4 ICD 名称 / 5 ICD |
| `11）診断群分類点数表` | 1 番号 / 2 **14 桁** / 3 傷病名 / 4〜8 手術・処置等１・処置等２・副傷病・重症度等の行名 / **9,10,11 入院日Ⅰ/Ⅱ/Ⅲ** / **12,13,14 点数Ⅰ/Ⅱ/Ⅲ** / 15 変更区分 / 16 開始日 |
| `12）変換テーブル ` | 1 14 桁 / 2 **包括フラグ** (1 包括対象 / 0 包括対象外) / 14〜18 各軸の値 |
| `13)出来高算定手術等コード ` | 0 区分 (00 移植術 / 01 厚労大臣指定) / 1 手術コード (**高額薬剤 107 行は空**) / 2 名称 / 3 変更区分 / 4 開始日 |

```python
x = pd.ExcelFile("/ext/doc-static/dpc/dpc_20260812.xlsx")
sheets = {n.strip(): n for n in x.sheet_names}
t = pd.read_excel(x, sheet_name=sheets["11）診断群分類点数表"], header=None, dtype=str)
t = t[t[2].str.match(r"^\d{2}[0-9x]{4}[0-9A-Zx]{8}$", na=False)]   # 14 桁の行だけ (3,267 本)
days2 = pd.to_numeric(t[10], errors="coerce")                       # 空 (包括対象外) と "-" (期間Ⅱなし) は NaN
print(len(t), (days2 >= 30).sum())   # 件数だけ出す。全行を print しない
```

- **14 桁の正規表現は `\d{2}[0-9x]{4}[0-9A-Zx]{8}`。** `\d{6}…` にすると分類コード末尾が `x` の 25 分類 (`01021x` 認知症 等、268 行) が落ちる
- **点数・入院日が空の行 = 包括対象外 (818 本)**、点数Ⅱ `-` = 期間Ⅱなし (6 本)。数値にするときは `errors="coerce"`
- 「手術を分岐に持つ分類」はシート 6 を K コードで濾す。**対応コード `97` の行も分岐に載っている手術** (点数表では「その他」に束ね)
- 変更区分 (全シート) は 0 = 前版と同じ。**0 でない行は開始日を見る** (この版では 3 + 29 行)
- xlsx には算定要件の文章も包括範囲の条文も無い。条件・解釈を聞かれたら doc (留意事項通知) に戻る
- 本文に出すのは件数と数例まで。全行・DataFrame 全体を print しない (context に全行を展開しないため。個人情報の制約ではない)。一覧を求められたら作業場所で CSV にし、それを `/workspace/exports/` へ写して渡す
