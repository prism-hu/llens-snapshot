# 感染対策マニュアルの引き方

`/ext/doc/院内マニュアル/感染対策マニュアル/` 配下。原本は院内イントラ「感染対策マニュアル」ページ
(第 8 版、2026-08-03 取得)。**節ごとに PDF が分かれており、1 ノード = 原本の 1 節**。
院内イントラ由来のコンテンツであり、**院外への持ち出し・外部公開・再配布をしない**。

医療安全管理マニュアル (`doc-safety-manual`) とは別の文書。あちらの各科マニュアルが
「感染対策マニュアルに従う」と委譲している先がここ。**感染に関する具体的手順の正典は常にこちら**。

このマニュアルが治療に触れるのは院内対応に要る範囲 (疥癬の治療薬の記載など) までで、推奨度つきの診断・治療の
推奨は診療ガイドライン側 (`doc-dermatology` / `doc-neurology` / `doc-lung-cancer`) にある。院内の隔離・予防策と
治療の推奨を両方聞かれたら、両方の skill を引いて出典を分けて答える。

## 入口

- 話題が構成のどこに属すか分かる → `list_doc` で章を辿る。不明 / 横断 → `grep_doc`
  (`path="/ext/doc/院内マニュアル/感染対策マニュアル/"` で絞る)
- ノード名は `NN_<節番号>_<タイトル>` (例 `02_14-2_針刺し・切創及び皮膚・粘膜曝露時の対応`)。
  本文の相互参照は節番号で書かれることがあるので、`grep_doc` に `"14-2"` のような
  節番号を渡すのも有効

## 回答規約

- 各ノードの meta: `section` = 節番号、`pages` = 節 PDF のページ数、`revised` = 改訂日
  (ISO)、`variant` = 院内用/院外用の別
- **第 8 版は 2026-03-01 一斉改訂**。節ごとに個別改訂日があるので、引用は
  「感染対策マニュアル 14-2 (2026-04-01 改訂) p.3」の形で節番号・改訂日・節内ページを添える
- 本文の【p.N】は**節 PDF 内のページ番号**。ノード末尾の「原本 PDF」を開いたときの
  ページと一致する (医療安全管理マニュアルの通しページとは別物なので混同しない)
- **院内用と院外用の 2 版がある節は院内用を収録**している (14-2 / 14-3)。院内職員への
  回答はこれで正しい。院外の実習生・委託業者に渡す内容を聞かれた場合のみ、院外用が
  別に存在することに触れる
- 本文は原本の文言そのまま。フローチャート・表・様式は**ページ画像から起こした再現テキストになっているページがある**。
  構造が怪しい表は留保を添える
- 図に触れるなら先に `feed_image(url=)` で見る (図の URL は戻り値の literal だけ。組み立てない)。ノード末尾の「原本 PDF」「様式」は再掲せず、そのリンクをラベルごとそのまま写して案内する (様式名を言い換えない・ファイル名を打ち直さない)
- 曝露事故・アウトブレイク等の緊急性がある質問では、**手順の逐語**と**連絡先**を最初に出す。
  電話番号は本文に出てくるものをそのまま引く (電話番号簿と食い違う場合は両方示す)
