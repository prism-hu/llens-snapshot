# 臨床スケール・計算式

## 規則 (毎回)

1. **定義を記憶で書かない。** 下の索引の path を `read_doc` で読み、そのノードの式・係数・配点・判定表・境界 (≥ と > の別) を使う。
   判定表だけのスケール (JCS・NYHA 等) も表を読んでから当てはめる。1 問で読むのはそのスケールのノードだけでよい
   (版を比べるときはその版のノードも)。「注意」にある他ノードの path は、その話題も答えるときに読む。
   同名で版が複数あるもの (MELD-Na と MELD 3.0、DIC 3 基準、国際版と日本版 Child-Pugh 等) は、ノードが示す使い分けに従い、どれを使ったかを書く
2. **計算は `run_python` で行う** (暗算しない。点数の足し算も、入力と配点を書いて合計させる)。
   入力はノードの「入力の条件と単位」に換算してから入れる (血小板の ×10⁴/µL と ×10³/µL の取り違えに特に注意)
3. **答える前に検算する。** 書いたコードにノードの「計算例」の入力を入れ、期待される出力と一致することを確かめる。
   一致しなければノードを読み直して自分のコードを直す (計算例に合うように係数をいじらない)
4. **答えには値・区分と、使った入力・単位・換算・式の版を書く。** 入力が会話に無ければ推測で埋めず確認する。
   一部の項目が欠けているときは、欠けた項目が取りうる最小〜最大で合計の幅を出す (減点項目もある。DIC_JSTH2017 の肝不全 −3 等)。
   幅全体が判定の境界の同じ側にあるときだけ判定を言い、それ以外は「暫定 (◯◯未入力)」と書く
5. ノードにある「未検証 (…)」は、括弧内の部分に答えが依存するときだけ一言添える (「原著未見」は転記元と照合済みなので添えなくてよい)。
   「注意」は、この入力で結果や判定が変わるもの (境界値ちょうど・原典間の食い違い等) だけを 1〜2 行書く
6. ノード冒頭の `## 出典` 節は原典と転記元の記録であって、回答の出典の代わりにしない。出典は通常どおりそのノードの path (`read_doc` の先頭の `path:` 行) を `[ ]` で囲んで主張の直後に付け、原典は聞かれたときだけ節の記載のまま「原典: …」として示す (節の外部 URL は院内の閉域ネットワークからは開けない)
