## 院内がん登録と全国がん登録は別制度 (最初にここで分ける)

同じ「がん登録」でも根拠も届け先も項目数も違い、**項目名が似ている**ので取り違えが一番起こりやすい。

- **院内がん登録** — がん登録等の推進に関する法律 第44条と大臣指針 (`/ext/doc/がん登録/院内がん登録標準登録様式2016/12_付録/01_院内がん登録の実施に係る指針.md`) に基づき、拠点病院等が**自院で持つ**登録。標準登録項目 **105**
- **全国がん登録** — 同法 第6条により、病院等の管理者が**都道府県知事に届け出る義務**。届出項目は **1〜26 + 備考**

**同名・ほぼ同名のノードが複数の文書に並ぶ。** `診断根拠` `発見経緯` `診断日` `側性` `診断施設`
`外科的治療…` は 3 文書すべてに、`進展度・治療前` `進展度・術後病理学的` `病理診断` `治療施設` は
2016 年版と全国の両方に、`症例区分` `来院経路` `生存最終確認日` は 2016 年版と 2006 年度版の両方にある。
「院内の標準登録様式では」なのか「全国がん登録の届出では」なのかで path を分け、**決まっているなら
必ず `path` で絞って grep** する。同名でも定義文は別物で、例示・注記・選択肢の細部が違う。

**登録対象そのものが違う。**

- 院内 (`/ext/doc/がん登録/院内がん登録標準登録様式2016/02_院内がん登録の登録対象.md`) — ICD-O-3.2 の性状コード 2 / 3 に加え、
  **例外として** a) 中枢神経系腫瘍 (良性・性状不詳を含む。対象局在コードを列挙) b) GIST c) 境界悪性卵巣腫瘍の一部
  (8442/1 等の形態コードを列挙)
- 全国 (`…/全国がん登録届出マニュアル2026/02_第1章_届出の対象と方法/01_届出の対象/…`) — 法律・施行令の
  「悪性新生物その他の政令で定める疾病」。政令疾病の範囲は付録［4］の対応表

**対応づけは推測せず、文書側が持っている 3 つの機構から取る。**

1. **2016 年版の各項目ノード末尾の【互換情報】** — 「2006 年度版 項目番号」「全国がん登録」「データ形式」の
   3 列で、**105 項目すべてに付いている**。全国がん登録に対応が無い項目はそこが「なし」
   (例: [550] 肝癌の病期、[860] 追跡期間)。**「全国がん登録にもあるか」はここで決まる**
2. **全国の届出項目ノードの冒頭の見出し表** — 「全国 14 / 院内 380」のように**両方の番号**が出る
   (並びが「全国 → 項目番号 → 用途 → 集計 → 院内」と入れ替わって見えるが、値は正しい)。
   `備考` にだけこの表が無い (項目番号を持たない項目のため)
3. **電子ファイル (CSV) 届出の項目対応表** — `/ext/doc/がん登録/全国がん登録届出マニュアル2026/05_付録/05_電子ファイルによる全国がん登録への提出形式.md`。
   院内 2016 年版の項目番号と全国の項目番号を連番で並べた表。**ここだけ「29 項目」**で、第2章の届出項目一覧
   (1〜26) とは数が違う。**件数を答えるときはどちらの数え方かを名乗る**

## 版は診断日で決まる (旧版を現行として答えない)

- **2016 年版は 2016-01-01 以降の新規診断症例**、それ以前は 2006 年度版修正版。**診断日を確かめずに版を選ばない。**
  診断日が分からないなら、両方の定義を並べて「診断日がいつかで版が変わる」と示す
- 2006 年度版のノードは **title がすべて `[2006年度版 …]` で始まる**。grep の戻りがこの接頭辞なら旧版で、
  **現行の登録ルールとして出してはいけない**
- **項目番号の体系が版で違い、同じ番号が別の項目を指す。**

  | 番号 | 2016 年版 | 2006 年度版 |
  |---|---|---|
  | 310 | 側性 | 進展度 (治療前) |
  | 450 | 来院経路 | 初回治療開始日 |
  | 580 | 進展度・治療前 | 内分泌療法の有無 |
  | 800 | 生存最終確認日 | 診療科 |
  | 810 | 死亡日 | 病棟 |

  **番号だけで答えず、どの文書の番号かを必ず添える。**
- **選択肢コードも版で違う。** 進展度・治療前は 2016 年版・全国が `400 上皮内 / 410 限局 /
  420 領域リンパ節転移 / 430 隣接臓器浸潤 / 440 遠隔転移 / 777 該当せず / 499 不明` の 3 桁
  (術後病理学的にはこれに `660 手術なし` が入る)、2006 年度版は `0 / 1 / 2 / 3 / 4 / 9`
  (術後病理学的にはこれに `8 適応外`) の 1 桁。**旧版の 1 桁コードを現行として出さない。**
  治療前と術後病理学的でも選択肢が違うので、**どちらの項目かを確かめてからコードを出す**
- **文書の版とは別に、項目の中で「◯年◯月◯日診断症例からは第 N 版」と分岐する** (【登録時の注意】)。
  例: [550] 肝癌の病期 (治療前・取扱い規約) は原発性肝癌取扱い規約 第4版 → 第5版 (2012-01-01〜) →
  第6版 (2016-01-01〜) → **第7版 (2026-01-01 診断症例〜)**。2006 年度版の 310/320 進展度も UICC TNM
  第6版 → 第7版 (2012-01-01〜) で切り替わる。**規約版・TNM 版はこの注意書きを読んでから言う**
- **2016 年版本体は 2026-07-27 の修正まで反映済み**だが、**表紙の更新日一覧と各ページの柱は「2026／4」と
  印字されたまま**である。印字された日付で版を判定しない。何がいつ変わったかを聞かれたときだけ
  `/ext/doc/がん登録/院内がん登録標準登録様式2016/99_修正履歴/` (`01_2026年7月27日` / `02_2026年4月1日` / `03_2025年9月9日` /
  `04_2025年6月16日`) を読む — **本文には反映済みなので、通常の質問で修正履歴を読む必要は無い**

## 引き方

- **総論・共通定義は項目ノードの外にある。** 登録対象・項目区分の記号・日付型項目の書式
  (`99999999` = 不明、`77777777` = 該当なし 等)・**がん治療と初回治療の定義**は、2016 年版なら top-level の
  リーフ `01_がん診療連携拠点病院等院内がん登録` 〜 `06_標準登録項目とその定義・凡例`、全国なら
  `/ext/doc/がん登録/全国がん登録届出マニュアル2026/03_第2章_届出項目について/01_届出項目の概説/` (`02_がん治療、初回治療の定義` `03_進展度について` を含む)。
  **個々の項目ノードはこの定義を前提に書かれている**ので、「初回治療とは」「進展度の考え方は」は
  項目ノードでなくここを読む
- **項目区分の記号が版で違う。** 2016 年版は **■ 共通項目 (全国がん登録への届出に要る) / ● 標準項目 /
  ◇ 管理項目** (加えて拡張項目 △)、2006 年度版は **◆ 必須 / ● 標準 / △ オプション**。
  **同じ ● でも意味が違う**ので、区分を答えるときは版を名乗る
- **項目番号が分かるなら番号で当てる。** 2016 年版は title も本文も `[580]` と**角括弧付き**、2006 年度版は
  `項目番号310` の形なので、書き方で版が分かれる: `grep_doc(query="[580]", path="/ext/doc/がん登録/院内がん登録標準登録様式2016/")`
- **2016 年版のリーフ path は `<項目番号 3 桁>_<項目名>`** (`580_進展度・治療前`)。ただし項目名の括弧と空白は
  落として `_` に畳んであり (`500_ステージ_治療前・UICC`、`510_TNM分類_UICC_T分類`、`705_外科的治療_他施設_自施設初回治療開始前`)、
  **項目名から path を組み立てると外す**。章は `07_基本情報` `08_腫瘍情報` `09_初回治療情報`
  `10_生存状況情報` `11_管理情報`。`07_基本情報` だけ原本と並びが違い、原本が先頭に置く [900] 病院等の名称 が
  文字列順で末尾に来る
- **2006 年度版は 1 ノード = 原本の 1 定義シート**で、関連項目をまとめたノードがある
  (`030-042_フリガナ・氏名・姓・名`、`160-170_診断区分・診断施設・治療方針`、`640-790_予後情報の全項目`)。
  末尾の解説文 (日付の書式・診断時住所について 等) をシート内の全項目で共有しているため割っていない。
  **1 項目 1 ノードを期待して path を作らず**、章を `list_doc` して title (全項目の番号と項目名が並ぶ) から選ぶ
- **全国は 章 → 区分 → 項目の 3 段** (`/ext/doc/がん登録/全国がん登録届出マニュアル2026/03_第2章_届出項目について/03_腫瘍情報/09_進展度・治療前.md`)。
  **path に項目番号は入っていない**ので項目名で辿る。Q&A 風のコラム 5 本は `コラム_` 接頭辞の独立ノード
- **横断で探すときも 3 文書に同名ノードが並ぶ。** どれか 1 つに決まっているなら `path` で絞る。
  絞らずに引くと版違い・制度違いのノードが混ざる

## 本文の読みにくさ (ここを外すと誤答する)

- **表の列は揃っている。**【コードの選択】の 3 列 (コード / 選択肢名 / 説明) と
  コード表の列対応は読めるが、**セルが折り返すと続きが次の行に落ちる**
  (`9654 ホジキンリンパ腫, リンパ球減少型, びまん性線` の次行が `維症性`)。
  ICD-O-3 の一覧は **1 行に「コード + 和名」の組が 2 つ並ぶ 2 段組**なので、行の右半分を別の行と読まない。
  **数値コード・和名を答えるときは原本 PDF リンクを添える** (`原本 PDF:` の行を普通のリンクのまま回答末尾にノードごとに 1 回。出典とは別)
- **図・様式・画面の見本は本文に中身が無い**: GTOL Web フォーム届出画面 (物理 p.21-23)、
  遡り調査票の見本 (p.73)、届出チャート (p.24。図中の語がばらけて出る)。ノード自身が冒頭でその旨を
  名乗るので、**中身を推測して埋めず**原本 PDF を案内する
- **印字ページと物理ページがずれる。** 2016 年版本体は **物理 = 印字 + 6** (巻末一覧表だけ 1〜4 に振り直し)。
  `【p.N】` と末尾の `原本 PDF` の `#page=N` はどちらも**物理ページ**で、原本に印字されたページ番号とは別物。
  **`99_修正履歴` と原本の目次が言う「頁」は印字ページ**なので、そのまま `#page=` に入れない
  (`04_2025年6月16日` のブロックに至っては**改訂前の版のページ番号**)
- 2006 年度版は各項目ページの柱に「第 N 版 更新日：YYYY/M/D」が残してある。**項目ごとに値が違い**、
  どの定義が 2012 年の改訂で書き換わったかの唯一の手がかり
- 2016 年版の本文は通常の漢字で収録してあるので、grep はそのまま当たる
  (原本 PDF では「行」「用」「生」「見」「：」が別字形に見えることがあるが、同じ字)

## 答えるときの注意

- **版と適用範囲を必ず添える。**「院内がん登録 標準登録様式 2016 年版 (2026-07-27 修正反映)」/
  「全国がん登録 届出マニュアル 2026」/「2006 年度版修正版【解釈本】= 2015 年 12 月以前の診断症例」。
  収録時点は 2026-09-11 で、発行元は随時修正を出す
- **コード値・項目番号・選択肢名は読んだノードの逐語で出す。** 記憶のがん登録知識で補わない。
  地域がん登録の旧標準登録票・ICD-10・DPC の病名コードと**混ぜない** (体系が別物)
- **個別症例のコーディングを断定しない。** 【コードの選択】【摘要】【登録時の注意】の該当箇所を引いて示す
  ところまでにし、当てはめは登録実務者・主治医の判断。「より進展した区分を選ぶ」「判定できないなら
  低い区分を選ぶ」のような**原本の判断規則はそのまま引用**して、こちらで適用しない
- **届出は法律上の義務で期限がある。** 対象・時期・方法を聞かれたら第1章のノードを読んでから答え、
  「届け出なくてよい」と読める答え方をしない
- **grep が 0 件でも「収録に無い」と即断しない。** この領域で効く当て方は、**項目名が版で違う**こと
  (2006 年度版「所属リンパ節転移あり」= 2016 年版「領域リンパ節転移」、2006「体腔鏡的治療」= 2016「鏡視下治療」、
  2006「予後調査」= 2016「生存確認調査」) を織り込んで別表記で引き直すか、章を `list_doc` で辿ること
- がん種別の診断・治療の推奨は **`doc-lung-cancer`** (肺癌・胸膜中皮腫・胸腺腫瘍) と
  **`doc-dermatology`** (皮膚悪性腫瘍 7 本: メラノーマ・有棘細胞癌・基底細胞癌・メルケル細胞癌・
  乳房外パジェット病・皮膚血管肉腫・皮膚リンパ腫)、有害事象の Grade は `doc-lung-cancer` の CTCAE、
  点数・算定は `doc-shinryo-hoshu` の領分。
  **このコーパスにあるのは登録の規則であって、病期分類の原典 (取扱い規約・UICC TNM) そのものではない。**
  **登録上のコードを診療上の判断に使わない** (進展度は登録用の粗い区分で、臨床病期そのものではない)
