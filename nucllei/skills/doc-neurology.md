## 入口

- **領域が分かる** → 上表の path を `list_doc` → 章 → CQ を選んで `read_doc`。CQ の一覧は章ディレクトリ (`…/<章>/`) の本文にも出るので、章を `read_doc` すれば下に何があるか分かる
- **どのガイドラインか分からない / 横断で探す** → `grep_doc(query="…", path="/ext/doc/診療ガイドライン/神経疾患/")`
- **ガイドラインを特定できているなら path で絞る** — `grep_doc(query="エダラボン", path="/ext/doc/診療ガイドライン/神経疾患/ALS2023/")`。薬剤名・症候は複数のガイドラインに散らばるので、絞らないと関係の薄いノードが上位を占める
- **CQ 番号の付け方はガイドラインごとに違う** (`CQ1` / `CQ03-1` / `CQ_II-2-01` / `CQ3A-01` / `14-01_治療総論` …)。**path を CQ 番号から組み立てない**
- 深さもガイドラインごとに違う (章 1 段のものから `頭痛2021/02_片頭痛/02_急性期治療/…` の 3 段まで)
- 紛らわしい兄弟が 2 つある: `/ext/doc/診療ガイドライン/神経疾患/てんかん2018/50_第2部_システマティックレビュー/` の CQ は第1部に同じ番号の短い CQ があるので **`CQ09-2_SR` / `CQ10-1_SR`** と `_SR` 付きで区別してある (両方読む)。`/ext/doc/診療ガイドライン/神経疾患/頭痛2021/99_English_digest/` は本体の英語ダイジェストなので、**日本語本文の CQ を正**とする

## 原本の示し方 (毎回やる)

**内容を説明しつつ、「原本のここです」を必ず一緒に出す。** 説明だけで終わらせない。

1. `read_doc` した本文の **`【p.N】` マーカー**を見て、引用・根拠にした文がどのページに載っているかを特定する (`【p.N】` の直後からそのページ)
2. ノード末尾の行 — `原本 PDF: [<ラベル> p.A–B](/ext/doc-static/jns_guidelines/docs/…#page=A)` — の**リンクをそのままコピーし、`#page=` の数字だけを 1 で特定したページに差し替える**
3. 「**原典: <ガイドライン名><年> <章 / CQ 番号> p.N**」+ そのリンク、の形で回答末尾にノードごとに 1 回添える (普通のリンクのまま。出典とは別)。複数ページにまたがるなら `p.N–M` と書き、リンクは先頭ページに向ける

例: `原本 PDF` の行が `原本 PDF: [ALS診療ガイドライン2023 p.26–29](/ext/doc-static/jns_guidelines/docs/als_2023.pdf#page=26)` のノード (`/ext/doc/診療ガイドライン/神経疾患/ALS2023/01_CQ/CQ1.md`) で p.27 の解説を引いたら `原典: ALS診療ガイドライン2023 CQ1 p.27 → [原本 PDF](/ext/doc-static/jns_guidelines/docs/als_2023.pdf#page=27)`

守ること (ここを外すと存在しないページ・存在しないファイルに案内する):

- **URL (`/ext/doc-static/jns_guidelines/docs/<ファイル名>.pdf` の同一サーバの相対 URL。ホストは補わない) は `read_doc` の戻り値にある literal を `#page=` の数字以外 1 文字も変えずにコピーする。** 上表のガイドライン名やディレクトリ名からファイル名を組み立てない (配信ファイル名は原本 URL 由来の英数字で、ディレクトリ名とは別物。配信 URL は `docs/<slug>.pdf` / `figs/<slug>-pNNN-fK.jpg` の短い英数字で、percent-encode は入っていない)
- **差し替えてよいのは `#page=` の数字だけで、その行が名乗る `p.A–B` の範囲内に限る。** 範囲外の数字を入れない。判断できなければ**差し替えず `原本 PDF` の行のリンクをそのまま出す**
- **1 ノードに `原本 PDF` の行が複数あることがある** (分冊 PDF・飛び地)。引用したページを含む区間の行を選ぶ
- `【p.N】` と `#page=N` はどちらも**その PDF の物理ページ**。本文中に印字されている本のページ番号 (柱・ノンブル) とは別物なので、印字された数字を `#page=` に入れない
- **章ディレクトリ (`…/<章>/`) の本文の `原本 PDF` 行は配下全体の範囲**。CQ を引いたなら、その CQ のノードの行を使う
- `原本 PDF` の行が無いノードで原本 PDF のリンクを**作らない** (出典は通常どおり主張の直後に付ける)。その場合はガイドライン名・章・ページだけを添える
- **引用は原文どおり短く。** 逐語引用は引用と分かる形 (かぎ括弧か引用ブロック) にし、自分の要約と混ぜない。見出しや推奨文の言い換えもしない

## 本文の読み方の注意

- **`神経疾患の遺伝子診断2009` は本文の数字が壊れている。** 章番号・図表番号・染色体座・MIM 番号・変異の位置・%・年・保険点数・文献の巻号ページが**欠落するか別の文字に化ける** (`100%`→`yzz%`、`SCA1`→`SCAy`、`22q11.2`→`¦¦qyy.¦`)。本文冒頭に引用ブロックの注意書きが出るので**それに従う** — 日本語の散文はそのまま読んでよいが、**数値は答えに使わず、原本 PDF (末尾リンク) を見るよう案内する**

- **図・アルゴリズム図・診断基準表は、ページ画像から起こした再現テキストになっているページがある**。フローチャートは矢印の向きを箇条書きにし、結合セルのある表は値を各行に展開してある。**原本に無い列名・辺・説明は足していない**ので、注記 (「原本に見出し行は無い」「原本では結合セル」「矢印は原図に描かれているものだけ」) はそのまま読者に伝える
- **図の切り出し画像がある** (403 点)。図に触れるなら先に `feed_image(url=)` で見て、リンクは戻り値の markdown をラベルごとそのまま使う (URL を組み立てない)。このコーパスで再掲がクリティカルになりやすいのは治療・診断アルゴリズム、判断樹、評価シート、家系図、フォレストプロット。**図が無く本文だけ再現されているページのほうが多い**ので、ページやファイル名の規則から「図があるはず」と推測しない
